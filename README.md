# aiwork

AI를 어떻게 쓰고 무엇을 만들었는지에 관한 글이 주제별로 쌓이는 공개 사이트. 로그인도 구독도 없다. 읽고, 프롬프트와 절차를 그대로 가져가고, 원하면 익명으로 의견을 남긴다.

이 저장소는 사이트이면서, 그 사이트를 운영하는 도구이기도 하다.

```
src/content/topics/   주제
src/content/posts/    글            ← 산출물
src/content/queue/    다음에 쓸 글 후보
aiwork/               aiwork MCP 서버 ← 기계
worker/               익명 댓글 (Cloudflare Workers)
```

## aiwork MCP

- **LLM을 호출하지 않는다.** 글은 사용자의 Claude가 쓰고, 도구는 재료·검사·게시·댓글만 한다.
- **마스킹 검사를 통과한 원고만 나간다.** 통과하면 사람 확인 없이 게시한다. 잘못 나간 글은 `unpublish`로 내린다.
- **저자 경험담은 지어내지 않는다.** 비어 있는 자리가 남은 글은 검사에서 막힌다.

첫 주제는 "AI 업무 비서": 직군이 무엇이든 내 업무 하나를 AI에게 넘겨 보는 7일 워크북과, 직군별 사례 글.

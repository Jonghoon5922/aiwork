계획은 "비용 대시보드"였는데 만들다 보니 "작업실"이 됐어요. 9월 한 달 동안 기능이 하나씩 붙을 때마다 Claude에게 시킨 건 "로컬 도구에 X를 더해 줘, 서버는 모르게"였고, 그 결과 서버보다 내 PC에서 도는 쪽이 커졌어요. 대표 문구를 바꾼 건 그 사실을 뒤늦게 인정한 거예요.

## 만들려던 것

프로바이더 사용량을 매일 모아 비용을 보여 주는 대시보드. 여기에 Claude Code 로컬 로그를 올려 리더보드를 만드는 업로더 하나.

## 실제로 만든 것

9월 기록만 보면 이래요.

- 9월 초: 구글 로그인 정리, 중복 집계 방지, 한·영 이중 언어, 회원 탈퇴.
- 9월 9일: **로컬 대화 뷰어.** Claude Code·Codex·Gemini 세션을 내 PC에서 열람하고 검색해요. 같은 날 Cursor 파서, 포탈에서 원클릭으로 여는 버튼, 필터 바까지 붙었어요.
- 9월 14일: **작업 보드**를 따로 있던 프로젝트에서 옮겨 심었어요. 도구 8개, 기록은 파일로만. 같은 날 AICV 포탈을 같은 컨테이너에서 서비스하도록 흡수했고, npm 정식 배포로 설치 명령을 한 줄로 바꿨어요.
- 9월 15일: **화면 개편** 다섯 단계. 헤더 버튼 10개를 드롭다운 2개로, 탭 구조(홈·사용량·리더보드), 차트 4개를 2개로, 배지 규칙 통일.
- 9월 17~18일: 보드에 스프린트(기간을 정하면 그 기간에 시작한 타스크가 자동으로 묶임), 날짜 축 타임라인, CSV·마크다운 내보내기. 그리고 대표 문구 변경.
- 9월 21일: **스킬·MCP 관리기.** 흩어진 스킬을 찾아 설치하고, MCP 설정을 모아 보고 내보내요.

## 계획과 달라진 것

**무게중심이 서버에서 로컬로 옮겨 갔어요.** 처음 설계는 서버가 중심이었는데, "대화 내용은 서버로 올리지 않는다"는 약속을 지키려니 쓸모 있는 기능은 전부 내 PC 쪽에 붙었어요. 뷰어, 보드, 스킬 관리기 셋 다 127.0.0.1에서만 돌아요. 서버는 숫자를 받는 입구로 남았어요.

**뷰어 버튼 하나에 커밋이 세 개 들어갔어요.** 포탈(https)에서 로컬(http) 뷰어를 여는 건 브라우저가 막는 조합이에요. fetch는 차단되고, 새 창은 참조가 끊기고, 구버전 뷰어는 응답 형식이 달라 오판했어요. 결국 "탐색은 항상 허용하고, 실패하면 토스트만"으로 정리했어요. 막는 쪽과 싸우지 않고 사용자가 뭘 해야 하는지만 알려 주는 게 답이었어요.

**스킬 관리기는 범위를 좁혔어요.** 처음 계획은 PC 전체에서 SKILL.md를 찾는 거였어요. 실제로 내려받은 폴더에 스킬 7개가 묻혀 있는 걸 봤으니까요. 그런데 그렇게 보여 주면 "여기 있는데 왜 안 읽혀요?"가 생겨요. Claude Code가 공식적으로 읽는 자리만 보기로 했고, 그 결정이 마지막 커밋이에요.

**화면은 덜어내는 쪽으로 갔어요.** 인사이트 카드를 없애고, 차트를 반으로 줄이고, 이모지는 트랙과 브랜드에만 쓰기로 규칙을 정했어요. 기능을 붙이는 속도만큼 화면이 복잡해져서, 개편은 다섯 단계를 계획 문서에 적고 하나씩 닫았어요.

## 실제로 시킨 말

프롬프트 원문은 남아 있지 않아요. 커밋 메시지가 그 역할을 해요. 이 프로젝트의 커밋은 "무엇을, 왜"를 한 줄에 담아요.

```
작업 보드 스프린트: 기간을 정하면 그 기간에 시작한 타스크가 자동으로 묶인다
작업 보드 버튼: 구버전 보드 오판으로 탭이 안 열리던 문제 — 탐색은 항상 허용, 실패 시 토스트만
스킬 관리: Claude Code 공식 스킬 폴더에서만 불러오기
```

Claude에게도 이 문장 그대로 시켰어요. "무엇을"만 말하면 엉뚱한 걸 만들고, "왜"까지 말하면 판단이 맞아요.

## 다음으로 넘길 것

스킬 관리기의 마무리(단위 테스트, 안내 한 줄, 배포)가 열려 있고, AICV 통합이 진행 중이에요. 테스트 단계 글은 이 둘이 닫힌 뒤에 써요.

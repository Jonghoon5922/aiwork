네, 모을 수 있어요. 토큰빌(Tokenbill)은 AI 코딩 도구로 일한 기록을 한곳에 쌓아 두고, 그 기록을 다시 쓸 수 있는 도구로 바꿔 주는 서비스예요. 설치는 명령 한 줄이고, 그다음부터는 손댈 게 없어요. 대화 내용 자체는 서버로 올라가지 않아요.

## 왜 만들었나

AI는 쓰고 나면 끝이에요. 어제 무슨 일을 시켰는지, 이번 달에 얼마나 썼는지, 그래서 내가 AI로 뭘 할 줄 알게 됐는지는 어디에도 남지 않아요. 로그 파일은 PC 어딘가에 쌓이는데 사람이 열어 볼 모양은 아니고요.

토큰빌의 생각은 하나예요. **AI는 쓰기만 하고, 기록은 토큰빌이 쌓는다. 쌓인 기록은 실력이 된다.** 처음 이름은 "내 AI 토큰, 한 화면에서"였어요. 사용량 대시보드로 시작했거든요. 그런데 기능이 붙을수록 비용을 보는 화면보다 일한 흔적을 다시 쓰는 쪽이 커져서, 대표 문구를 "내 AI 작업실"로 바꿨어요.

## 무엇이 들어 있나

기능은 네 갈래예요. 각자 하나의 질문에 답해요.

- **리더보드**: 이번 달 얼마나 썼나. Claude Code, Codex, Gemini CLI, API 사용량으로 순위를 매기고 매달 새 판이 열려요.
- **대화 뷰어**: 무슨 일을 했었나. 지난 AI 대화를 한곳에서 검색해요. 내 PC에서만 돌아요.
- **작업 보드**: 지금 뭘 하고 있나. AI 세션이 스스로 남기는 일감 기록이에요. 이것도 내 PC에서만 돌아요.
- **AICV**: 그래서 뭘 할 수 있나. 작업 로그가 근거가 되는 AI 활용 이력서예요.

작업 보드가 제일 특이해요. 사람이 할 일을 적는 보드가 아니라, Claude가 일하면서 직접 적는 보드예요. 창을 열고 일을 시키면 Claude가 그 일을 타스크로 만들고, 진행하면서 한 줄씩 남기고, 끝나면 마무리를 적어요. 사용자는 보드를 열어 보기만 하면 돼요. 보드는 창을 연 폴더, 그러니까 프로젝트별로 나뉘어 보이고, 기간을 정하면 그 기간에 시작한 타스크가 스프린트로 묶여 날짜 축 타임라인에 그려져요. 보이는 타스크는 CSV나 마크다운으로 내보낼 수 있어요.

최근에는 **스킬·MCP 관리기**가 뷰어에 붙었어요. AI를 오래 쓰다 보면 스킬과 MCP 설정이 여기저기 흩어지는데, 그걸 한 화면에 모아 보고 쓰는 자리로 옮기는 기능이에요.

## 어떻게 쓰나

Claude Code라면 터미널에 이 한 줄이에요. 토큰은 tokenbill.my에 가입하면 받아요.

```bash
claude mcp add -s user tokenbill -- npx -y tokenbill-mcp@latest --token <내 토큰>
```

등록하고 Claude Code 창을 새로 열면 세 가지가 함께 돌아요.

1. 창을 열 때마다 로컬 사용량 로그를 요약해서 tokenbill.my에 올려요. 리더보드는 이걸로 그려져요.
2. 대화 뷰어가 내 PC에서 열려요. 이 PC의 로그만 읽어요.
3. 작업 보드가 내 PC에서 열려요. 기록은 내 PC에 파일로만 남아요.

작업 보드를 제대로 쓰려면 Claude에게 따로 말할 필요가 없어요. 일을 자연어로 시키면 Claude가 알아서 타스크를 만들거나 이어 붙여요. 처음 써 볼 때는 이 정도로 시켜 보세요.

```
이 저장소 README에 설치 방법 절을 추가해 줘. 작업은 타스크로 남겨 줘.
```

끝난 뒤 보드를 열어 보면 타스크 하나와 진행 로그 몇 줄이 생겨 있을 거예요.

## 어디까지 내 PC에 남나

이 부분은 설계에서 제일 먼저 정한 거예요.

- 대화 내용, 작업 보드 기록, 스킬·MCP 설정은 **서버로 올라가지 않아요.** 로컬에서만 동작해요.
- 서버로 가는 건 사용량 요약이에요. 날짜, 도구, 모델, 토큰 수 같은 숫자예요.
- 스킬·MCP 관리기는 설정 파일을 읽을 때 **토큰이나 키로 보이는 값을 바로 가려서** 화면에 보여 줘요. 다른 PC로 내보낼 때도 키 자리를 자리표시자로 바꾼 템플릿을 만들어요.
- 스킬 관리기가 쓰기를 하는 곳은 Claude Code의 개인 스킬 폴더 하나뿐이에요. 그 밖으로 나가는 쓰기는 거절해요.

## 무엇을 포기했나

스킬 관리기는 처음에 PC 전체에서 SKILL.md를 찾으려 했어요. 내려받은 폴더나 다른 도구 폴더에 묻혀 있는 스킬까지요. 그런데 그렇게 하면 "여기 있는데 왜 안 읽혀요?"가 생겨요. 그래서 **Claude Code가 공식적으로 읽는 자리만** 보기로 했어요. 개인 스킬 폴더, Claude Code가 기억하는 프로젝트 폴더의 스킬, 플러그인 스킬(읽기 전용)이에요. 화면에 보이는 스킬은 실제로 읽히는 스킬이에요.

내보내기도 처음엔 zip으로 묶으려다가 폴더 복사와 MCP 템플릿으로 바꿨어요. 받는 쪽에서 풀고 옮기는 단계가 하나 줄어요.

AICV는 원래 따로 있던 서비스였는데, 토큰빌 기능으로 합치는 중이에요. 작업 로그가 증거가 되는 이력서라면, 로그를 쌓는 곳과 같은 데 있는 게 맞다고 봤어요.

## 이런 분께 맞아요

- Claude Code를 여러 창, 여러 프로젝트에서 동시에 쓰는데 어디서 뭘 했는지 헷갈리는 분
- 지난주에 AI랑 풀었던 문제를 다시 찾고 싶은데 대화가 어디 있는지 모르는 분
- 스킬과 MCP가 늘어서 뭐가 어디 깔렸는지 정리가 필요한 분

사용량 숫자에만 관심 있다면 리더보드만 보셔도 돼요. 그래도 작업 보드는 한 번 켜 두세요. 일주일 뒤에 보드를 열면 그 주에 AI랑 한 일이 저절로 정리돼 있어요.
